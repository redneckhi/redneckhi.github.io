**RHI Mesh Protocol** is software for when the cell tower is a rumor and you still need to pass coordinates.

## Capabilities

- Store-and-forward messaging over LoRa / Wi-Fi / serial bridges
- Simple packet format you can decode with a hex dump
- Priority lanes for SOS and position beacons
- Runs on Linux SBCs and capable Android handsets

## Who it is for

Teams who need a boring, inspectable mesh — not a black-box messenger with a venture-backed privacy policy.

Buy opens the protocol notes and reference node build so you can stand up your own network.
