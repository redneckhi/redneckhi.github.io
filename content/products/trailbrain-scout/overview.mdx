**Trailbrain Scout** is an edge AI kit for classifying motion events on trail cameras and cheap IP cams without shipping every frame to someone else's GPU farm.

## Highlights

- Runs quantized models on NPU / CPU boards
- Offline alert rules you can edit as JSON
- Exports event clips to local storage or mesh nodes
- Tuned for “is this a person / vehicle / animal?” triage

## Fit

If you need forensic-grade recognition, look elsewhere. If you need good-enough triage in the woods, this is the brief.
