Overview

Admin Dump Pouch Mk.II is a sew-it-yourself pattern for an open-top dump pouch with a minimal admin face. Designed to stay open under gloves and dump water when it has to.

Dimensions

  • Opening: ~150 mm wide
  • Depth: ~180 mm
  • Admin sleeve: 110 × 70 mm clear or opaque

Scale freely; keep proportions if you change size.

Materials

  • 500D–1000D nylon
  • 25 mm webbing for MOLLE straps
  • Binding tape
  • Plastic or kydex strip for rim stiffener (~12 × 300 mm)
  • #0 grommet + washer
  • Velcro hook/loop for admin closure (optional)

Pattern pieces

  1. Body rectangle (front + back + bottom as one wrap, or separate panels)
  2. Rim channel strip
  3. Admin sleeve
  4. MOLLE straps (×3)

Construction

Body

  1. Cut body; mark grommet center on bottom
  2. Install grommet before assembly if access will be tight
  3. Seam sides; bind raw edges

Rim

  1. Fold rim channel; insert stiffener
  2. Topstitch so the rim holds a round mouth
  3. Confirm one-handed open with gloves on

Admin sleeve

Sew sleeve to face. Leave top open or add a small Velcro tab. Do not overstuff — the pouch is for dumps, not a filing cabinet.

MOLLE

Attach three vertical webbing straps to the back with box-x stitches. Weave into carrier as needed.

Field notes

If the rim collapses, your stiffener is too soft or the channel too wide. If water pools, enlarge or clear the grommet. If admin cards vanish, add a bit of loop Velcro — Mk.II assumes you will revise.

Care

Brush mud out dry. Rinse salt. Air dry fully before packing so mildew does not become part of the kit.
